# Nash Directory

This directory contains the implementation of a Nash Equilibrium algorithm. It is still wip, 
and is not yet fully working. The algorithm attempts to find a Nash Equilibrium for a given game, 
and is based on Robert Wilson's algorithm for finding a Nash Equilibrium.

## Files

### `main.py`
This file contains the main implementation of the Nash Equilibrium algorithm.

### `nash_tests.py`
This file contains the tests for the Nash Equilibrium algorithm.
